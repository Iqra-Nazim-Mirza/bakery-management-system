# Bakery Bloom - Full Stack Bakery Management System

Stack: React + JavaScript + Node.js + Express + MySQL.

## Run
1. Create the MySQL database by running `database/schema.sql`, then `database/seed.sql`.
2. Copy `backend/.env.example` to `backend/.env` and set your MySQL credentials.
3. In `backend`: `npm install` then `npm run dev`.
4. In `frontend`: `npm install` then `npm run dev`.
5. Open the Vite URL shown in the terminal.

The interface follows the supplied Bakery Bloom reference: cream/pink/brown/cherry palette, customer/admin switch, product cards, cart, custom cake order, tracking, history, dashboard, orders and inventory.
